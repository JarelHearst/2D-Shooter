# Unity 2D shooter top-down Project

## A fast-paced 2D top-down shooter built in Unity and C#, featuring multi-level progression, enemy waves, dynamic combat, and score tracking.

My 2D Shooter is a fast-paced top-down shooter developed in Unity using C#. Players battle waves of enemies across multiple levels while earning points and working toward each level's victory condition. The project features custom systems for player movement, projectile-based combat, enemy spawning, health and damage, scoring, and UI management. I followed University of Michigan's course on coursera to help me with this project to understand the fundamentals of Unity. The project also gave me hands-on experience with Unity's Input System, scene management, and persistent high-score tracking.

* Developed a 2D top-down shooter in Unity using C#, implementing core gameplay mechanics and reusable game systems.
* Programmed player movement, mouse aiming, projectile-based combat, enemy spawning, and collision detection using Unity's component-based architecture.
* Built reusable health, damage, and enemy systems to manage combat interactions, player lives, and enemy behavior.
* Implemented multi-level progression, victory conditions, game-over states, and scene management across multiple playable levels.
* Created a score and high-score system using Unity PlayerPrefs to persist player performance between game sessions.
* Integrated the Unity Input System for responsive keyboard, mouse, and gamepad-compatible player controls.
* Developed interactive UI systems including the main menu, pause menu, score display, victory screen, and game-over screen.
* Applied object-oriented programming (OOP), C# scripting, Unity 2D physics, prefab workflows, and component-based game architecture throughout development.

## How to install 

Download 2D Shooter here: https://jarelhearst.itch.io/2d-shooter

Installation
Visit the 2D Shooter itch.io page using the link above.
Click the Download button.
Download the game files to your computer.
Extract the downloaded .zip file.
Open the extracted folder.
Double-click the game's .exe file.
Start playing! 🎮

Windows: If Windows displays a security warning, select More info → Run anyway if you trust the download.

🎮 Controls
WASD / Arrow Keys — Move
Mouse — Aim
Left Mouse Button — Shoot
ESC — Pause
